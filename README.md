# 🧬 Diabetic Nephropathy – South Korea Dataset

This repository contains code and data processing pipelines for predicting binary renal outcomes in South Korean patients with **Diabetic Nephropathy (DN)**. The targets include:

- **End-Stage Kidney Disease (ESKD)**
- **2-Year Composite Outcome**
- **3-Year Composite Outcome**
